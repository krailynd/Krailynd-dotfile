# archlinux-krai

Personal Arch Linux desktop configs for Krai — coming soon.

## Status

Placeholder folder reserved by `install.sh` profile selector. Will hold Hyprland / Waybar / zsh / nvim / pacman configs when uploaded.

## Planned structure

```
archlinux-krai/
  shell/   # zsh, p10k
  hypr/    # hyprland.conf, waybar, wofi
  nvim/    # LazyVim
  pacman/  # pkglist.txt
```

Until populated, selecting `archlinux-krai` in `install.sh` prints a notice and installs nothing.
