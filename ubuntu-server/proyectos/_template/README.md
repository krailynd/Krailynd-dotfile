# _template

Minimal new-project scaffold. Copy to start a new project:

```bash
cp -r ~/SahaCloud/projects/Krailynd-dotfile/ubuntu-server/proyectos/_template ~/SahaCloud/projects/my-project
cd ~/SahaCloud/projects/my-project
git init
```

## Structure

```
my-project/
├── README.md
├── CLAUDE.md   # project context for opencode/hermes
└── .gitignore
```

Fill `CLAUDE.md` with project-specific stack, commands, and conventions.
