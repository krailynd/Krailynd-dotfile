# Generación de Retratos y Personajes por IA

```bash
python3 ~/.local/bin/local-image-gen.py --prompt "Detailed portrait of <personaje>, <estilo>, cinematic lighting, sharp focus" --out /ruta/retrato.png --model flux-realism --width 1024 --height 1024
```

Para estilo anime: `--model flux-anime`.
