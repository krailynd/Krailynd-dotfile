```ics

DTSTAMP:{now_utc}
DTSTART;TZID=America/Lima:{start_datetime}
DTEND;TZID=America/Lima:{end_datetime}
RRULE:FREQ=WEEKLY;BYDAY={MO,TU,WE,TH,FR,SA,SU};UNTIL={semester_end}
SUMMARY:{event_title}
DESCRIPTION:{description_template}
CATEGORIES:{calendar_category}
COLOR:{color_hex}
TRANSP:{OPAQUE|TRANSPARENT}
STATUS:CONFIRMED
BEGIN:VALARM
ACTION:DISPLAY
DESCRIPTION:{reminder_message}
TRIGGER:-PT{minutes}M
END:VALARM
END:VEVENT
```

## Generation Script (Python)

```python
#!/usr/bin/env python3
# generate_ics.py — generates 6 ICS files from schedule config
# Usage: python generate_ics.py config.yaml output_dir/

import yaml
from ics import Calendar, Event
from datetime import datetime, timedelta
import uuid

def create_calendar(name, color, events, tz='America/Lima'):
    cal = Calendar()
    cal.extra.append(f'X-WR-CALNAME:{name}')
    cal.extra.append(f'X-WR-CALDESC:Generated by academic-schedule-integration')
    for ev in events:
        e = Event()
        e.uid = f'{uuid.uuid4()}@academic-schedule-integration'
        e.name = ev['summary']
        e.begin = ev['dtstart']
        e.end = ev['dtend']
        e.description = ev['description']
        e.categories = [ev['category']]
        e.transparent = ev.get('transparent', False)
        e.status = 'CONFIRMED'
        # Recurrence
        if 'rrule' in ev:
            e.rrule = ev['rrule']
        # Alarms
        for alarm in ev.get('alarms', []):
            e.alarms.add(alarm)
        cal.events.add(e)
    return cal

# Config loaded from YAML with schedule, roadmap mapping, personal constraints
# Outputs 6 .ics files ready for Google Calendar import
```

3. Select file → Choose target calendar (create new for each) → Import
4. Repeat for all 6
5. Verify: colors, recurrence, reminders, descriptions visible
6. Set default calendar for new events → `Deep Work` (green)
