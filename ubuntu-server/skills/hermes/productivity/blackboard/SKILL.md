# Blackboard Learn — UPSJB Course Access

Access Blackboard Learn for Universidad Privada San Juan Bautista (UPSJB). Two paths: browser automation (primary, since Blackboard uses Microsoft OAuth) or REST API (if a token is available).

## Institution specifics

- **URL:** `https://upsjb.blackboard.com/`
- **Auth method:** Microsoft 365 / Office 365 OAuth (not direct Blackboard credentials)
- **Login domain:** `@upsjb.edu.pe` (e.g., `YOUR_UNI_EMAIL`)
- **MFA:** SMS or phone call after credentials. Always choose SMS.
- **Help article:** https://sae.upsjb.edu.pe/hc/es-419/articles/26571464223131-Acceso-a-la-plataforma-Blackboard

## Browser automation path (primary)

1. Navigate to `https://upsjb.blackboard.com/`
2. Accept cookie/privacy dialog if present
3. Click "Inicia sesión con Office 365" (NOT "Iniciar sesión como postulante")
4. This redirects to `login.microsoftonline.com` — the Microsoft OAuth flow
5. Enter `usuario@upsjb.edu.pe` in the email field, click Next
6. Enter password on the password page
7. Handle MFA: choose SMS (not phone call), wait for code, enter it
8. After auth, Blackboard dashboard loads — browse activity stream, courses, announcements

## REST API path (alternative)

Blackboard Learn has a REST API at `https://upsjb.blackboard.com/learn/api/public/v1/`. Requires an API token generated by a Blackboard admin — not currently available for this user. If obtained:

```bash
# List courses
curl -s -H "Authorization: Bearer $BLACKBOARD_TOKEN" \
  "https://upsjb.blackboard.com/learn/api/public/v1/courses"
```

## Troubleshooting browser automation

| Problem | Fix |
|---------|-----|
| Browserbase 502 Bad Gateway | Transient service issue — retry after a few minutes, or fall back to Playwright MCP |
| Playwright: "Chromium distribution 'chrome' is not found" | Run `npx playwright install chrome` (requires npm project with `@playwright/test` installed first) |
| `npx playwright install` fails with "install your dependencies first" | Need `npm install @playwright/test` in a project directory first, then retry |
| Playwright install needs sudo | Requires root access on the server |
| Page goes blank after cookie dialog | Re-navigate fresh; cookie dialogs can interfere with snapshot state |

## Pitfalls

- **NEVER ask the user for their password in plaintext.** If browser automation is the path, the agent navigates the flow. The user should only provide credentials through the browser session itself, not typed into the chat. Chat history is stored in session databases and logs.
- **Do not use "Iniciar sesión como postulante"** — UPSJB students use the Office 365 link.
- **Blackboard session times out** after inactivity. If the browser snapshot goes stale, re-authentication may be needed.
- **MFA SMS has a timeout** — typically 5-10 minutes. If the code doesn't arrive, retry or switch to phone call.
